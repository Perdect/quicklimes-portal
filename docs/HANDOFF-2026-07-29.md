## Business Logic

- **Money excludes duplicates.** A row flagged `duplicate` is the same bank line imported twice. `summaryHTML()` sums only `statusKey(t) !== 'duplicate'`. Counts still show duplicates; only money excludes them.
- **WhatsApp only for mobiles.** `WACore.isMobileNumber()` reads the RAW string: landlines carry an STD grouping (`79 4023 5235`) or a trunk 0; mobiles are one 10-digit run or 5+5. Biased to hiding — a hidden button costs one tap on Call, a shown one opens a dead chat.
- **Outreach signature** comes from Settings → Company profile (name/phone/address), never hardcoded, so each company signs as itself.
- **Export = what is on screen**, i.e. current tab + filters.
- **Stage moves send the whole lead** (`leadPatch`). `upsertLead`'s UPDATE rewrites every column it picks, so a partial payload is a silent delete.

## Edge Cases Handled

- Backwards date range (From after To) is **swapped**, not left silently empty.
- Filter bar stays live when filters return zero rows (`wireTable()` runs in both branches).
- `.dc-float[hidden]` — a class `display:flex` outranks the UA `[hidden]` rule.
- State polygons: one polygon **per ring**, or Leaflet treats them as holes and the fill cancels.
- `.rc-dp` was already the detail-panel drawer; date presets use `.rc-dpb`.
- `repaintList()` replaces blocks **by class** — a rename must update its selector in the same edit.
