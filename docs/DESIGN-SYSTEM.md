# QuickLimes — Design System & Project Reference
Single source of truth: **`dashboard/v2/tokens.css`**. Nothing should use raw values — everything inherits from these tokens (radius, type, and CSS colours are now **test-enforced**: `radius-tokens.test.js`, `type-tokens.test.js`, `color-tokens.test.js`).

Stack: **vanilla JS + CSS custom properties**, no framework, no build step. PHP + MySQL backend. PWA (service worker). Font: **Geist** (mono: Geist Mono).

---

## 1. Colour tokens
Semantic scales — light values shown; theme-adaptive aliases flip in dark mode.

| Role | Token(s) | Value |
|---|---|---|
| **Primary / brand** | `--ql-brand-600` (action), 50–900 scale | `#2563EB` |
| **Success** | `--ql-success-600`, 50/100/500/700 | `#16A34A` |
| **Warning** | `--ql-warning-600`, 50/100/500/700 | `#D97706` |
| **Danger** | `--ql-danger-600`, 50/100/500/700 | `#DC2626` |
| **Neutral** | `--ql-neutral-0…900` | `#FFFFFF … #0F172A` |
| **Surface** | `--ql-card` / `--ql-bg-elevated` | `#FFFFFF` |
| **Background** | `--ql-bg` | `#F8FAFC` |
| **Border / divider** | `--ql-border` / `--ql-divider` | `#E2E8F0` / `#F1F5F9` |
| **Text** | `--ql-text` / `-secondary` / `-muted` | `#0F172A` / `#64748B` / `#94A3B8` |

**Theme:** defaults to **Light**; System/Dark are explicit choices in Settings → Appearance. Raw scale tokens (`neutral-N`, `brand-N`…) are theme-constant; only aliases (`--ql-text`, `--ql-bg`, `--ql-border`) flip in dark.

## 2. Type scale (`--ql-text-*`)
`2xs 10 · xs 11 · sm 12 · base 13 (body) · md 14 · lg 16 · xl 18 · 2xl 22 (card values) · 3xl 28 (H1) · 4xl 32 (hero)`
Weights: regular 400 · medium 500 · semibold 600 · bold 700 · black 800. Leading: tight 1.2 / snug 1.35 / base 1.5 / loose 1.7.

## 3. Spacing (`--ql-space-*`, 8-pt grid)
`0 · 1=4 · 2=8 · 3=12 · 4=16 · 5=20 · 6=24 · 8=32 · 10=40 · 12=48 · 14=56 · 16=64`

## 4. Radius (`--ql-radius-*`)
`xs 4 · sm 6 · md 8 (control) · lg 8 · xl 10 · 2xl 12 (card) · 3xl 14 · 4xl 16 · 5xl 20 · pill 9999`

## 5. Elevation (`--ql-shadow-*`)
`xs · sm · md · lg · xl` (soft slate shadows) · `ring` (focus, 3px brand glow) · `inset`

## 6. Motion
Duration: fast 120ms · base 180ms · slow 280ms. Easing: `--ql-ease-out` cubic-bezier(.16,1,.3,1).

## 7. Universal List-Header (register toolbar) — the standard
The shared component is QLX's `toolbarHTML` (`qlx.js`), used by Sales, Purchase, Payments, Cashbook, TDS. Spec (aligned 2026-07-30):
- **Bar** 64px (12/24 padding), **gap** 12px, sticky top
- **Order (never changes):** Month/date filter → status tabs (with counts) → search → Group → Filters → Columns → module extras (Ledger/Audit/Export/Import)
- Controls **40px**, radius **xl (10)**, icons **18px**, **search 320px**
- ⚠️ **Bank Reconciliation** (`reconcile.js`) has its own toolbar (status dropdown + account tabs + Ledger/Audit views) — **not yet aligned** to this spec; tracked as the next step.

## 9. Architecture
- **Shared JS cores:** `data.js` (state + persistence + tenant blob), `shell.js` (nav/theme/topbar), `qlx.js` (the register table+toolbar component), `mobile.js`, `recon-core.js`/`recon-apply.js` (reconciliation), `crm-core.js`, `freight-core.js`, `wa-core.js`, `bill-ocr.js`.
- **CSS:** `tokens.css` (source of truth) + `shell.css`, `pages.css`, `qlx.css`, `mobile.css` + per-module (reconcile/pbill/dash/finance/report/…).
- **API (PHP):** `login`/`signup` (bcrypt + HMAC tokens, rate-limited), `data` (tenant blob, rev-guarded), `files` (bill scans), `recon`, `crm`, `discover`, `extract` (AI/vision), `wa`/`wa-hook` (WhatsApp), `chat`, `freight`, `jobs`/`cron`, `plant`/`company`/`onboard`/`users`.
- **DB:** MySQL, every table `(plant_id, company_id)`-scoped; the whole business dataset is one JSON blob per company in `app_data` (see audit P1).
- **Cache-busting:** every asset carries `?v=`; a service-worker `CACHE` version + `asset-versions.json` (regenerated by `version-sync.test.js --update`).
- **Tests:** ~98 JS suites + ~12 PHP suites, mutation-tested.
