Backend migration

Move your data to Hostinger

This one-time tool copies your QuickLimes data from this browser into your new Hostinger MySQL database, and sets your login password. Run it once, on the device where you normally use QuickLimes.

Set your login password
You'll use your phone number + this password to log in from now on. Choose something only you know (min 4 characters).
Re-running this? (advanced)
The first run needs nothing extra. If the database already has an account, paste the APP_SECRET from your config.php here to overwrite it.
Before you click: make sure you've created your MySQL database in hPanel and saved your credentials into app/api/config.php on the server (copy it from config.example.php). Without that, this can't connect.

Migration complete 🎉
